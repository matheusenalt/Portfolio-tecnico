# Plano de evolução técnica

O objetivo deste repositório é documentar minha evolução em infraestrutura Linux e operações Cloud, com atividades que possam ser reproduzidas.

| Frente | Próxima entrega pretendida | Status |
|---|---|---|
| Administração Linux | Laboratório de usuários, permissões, serviços e logs | Planejado |
| Docker e redes | Monitoramento e cenários de falha em containers | Planejado |
| Backup | Exercício de retenção e restauração com falha simulada | Planejado |
| Redes e segurança | Documentação de firewall, SSH e diagnóstico de conectividade | Planejado |
| Cloud pública | Laboratório introdutório com controle de custos e serviços básicos | Em estudo |
| CI | Ampliar testes, lint e verificações de segurança | Em evolução |

As tarefas marcadas como planejadas ainda não são entregas disponíveis. Cada novo laboratório terá instruções de execução, resultado esperado e limitações descritas no README correspondente.
