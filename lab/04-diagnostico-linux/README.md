# Laboratório 04 · Checklist básico de diagnóstico Linux

Script de demonstração de **somente leitura** para exercitar checagem inicial de um host. Exibe data UTC, versão do kernel, uptime, disco da partição raiz, memória e disponibilidade de algumas ferramentas. Não usa `sudo`, não acessa a rede e não altera configurações.

```bash
bash lab/04-diagnostico-linux/check_host.sh
```

> Em ambientes profissionais, a saída pode incluir detalhes operacionais. Use apenas em seu próprio laboratório e **não publique logs reais**. Isso não equivale a monitoramento permanente ou auditoria completa de segurança.
